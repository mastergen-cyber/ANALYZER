# Mastergen Software — одностраничный сайт

## Как опубликовать бесплатно и редактировать

1. Создайте бесплатный аккаунт на [GitHub](https://github.com/signup), если его ещё нет.
2. Создайте новый **публичный** репозиторий с именем `ваш-логин.github.io`.
3. Загрузите в него всё содержимое этой папки, включая каталог `assets`.
4. Откройте в репозитории **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите Save.
5. Через несколько минут сайт появится по адресу `https://ваш-логин.github.io`.

Чтобы менять сайт, открывайте свой репозиторий на GitHub: нажмите файл `index.html` или `styles.css`, затем значок карандаша и **Commit changes**. Это и будет ваша постоянная ссылка для редактирования: `https://github.com/ваш-логин/ваш-логин.github.io`.

Перед публикацией при необходимости замените `#contact` и `#video` в `index.html` на нужные ссылки (почта, Telegram, YouTube и т. п.).

Важно: бесплатный адрес GitHub Pages — это постоянный поддомен `ваш-логин.github.io`, пока существует ваш аккаунт и репозиторий. Полноценный собственный домен (`.com`, `.ua` и т. п.) обычно требует ежегодной оплаты.
